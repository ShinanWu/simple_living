# 前端跨端交互共识（全局）

## 1. 目标

本文是 `Web / iOS / Android / 微信小程序` 全前端交互的统一语义文档，用于约束：

- 用户可感知行为一致
- 状态与恢复路径一致
- 埋点语义一致

后续新增页面或功能的交互规则，默认都先落在本文，再进入分端实现文档。

## 2. 适用范围

- 首页、详情页、跳转准备页、我的页
- 后续新增页面与组件交互
- 全局导航、手势、反馈、异常恢复、埋点语义

## 3. 不可分叉原则（必须一致）

### 3.1 任务语义一致

- 相同行为在三端表达同一业务意图
- 不允许因平台差异改变核心任务路径

### 3.2 状态语义一致

- 页面状态统一为：`loading` / `success` / `empty` / `error` / `offline`
- 同类状态文案和恢复动作保持同语义

### 3.3 交互触发时机一致

- 关键动作触发时机跨端一致（例如“刷新在松手时判定”）
- 可以调整阈值与动画，但不能改变触发条件语义

### 3.4 契约消费一致

- 前端交互不得发明与 `gateway` 契约冲突的字段语义
- 埋点字段命名与含义在三端保持一致

## 4. 全局交互规则

### 4.1 导航与返回

- 底部导航（或小程序等等价主导航）仅支持点按切换，禁止仅靠滑动误切主 Tab
- 系统返回优先级高于页面自定义手势
- 返回后应恢复用户最近一次可理解上下文

### 4.2 手势冲突处理

- 横向与纵向手势按主方向判定，禁止同时触发
- 拖拽手势进行中，不得误触发点击进入
- 非关键区域手势不得抢占关键操作区域

### 4.3 加载与反馈

- 首屏加载提供明确反馈，不阻塞核心导航结构
- 长请求需要可见状态与可恢复入口
- 重试按钮语义统一为“重试当前操作”

### 4.4 空态与异常恢复

- 空态给出下一步动作（重试或返回）
- 异常优先恢复当前任务，再建议返回上一级
- 离线态明确提示并允许用户重试

## 5. 首页（Home）共识规则

### 5.1 首页结构

- 顶栏：搜索框（占位，v1 点击提示"搜索功能即将上线"）+ 右侧「我的」入口图标
- 主区：单屏单卡片（一次只展示 1 条推荐）
- 底部：主题切换栏（衣、食、住、行）

### 5.2 顶栏规格

- 搜索框与「我的」图标在同一行，搜索框占主要宽度，「我的」图标固定在右侧
- 搜索框为只读占位态，placeholder 文案统一为「搜索少糖推荐」
- 点击搜索框：v1 弹出提示"搜索功能即将上线"；v2 跳转搜索页
- 点击「我的」图标：导航到我的页
- 顶栏高度紧凑，不使用卡片容器，最大化卡片区可用空间

### 5.3 手势语义

- 左滑/右滑：切换 `衣/食/住/行`
- 上滑：下一条推荐
- 下滑（非第一页）：上一条推荐
- 下滑（第一页）：进入二段式刷新判定

### 5.4 刷新判定

- 下拉过程中只更新视觉反馈，不触发请求
- 仅在松手时判定是否刷新
- 松手时位移 >= 刷新阈值：触发刷新
- 松手时位移 < 刷新阈值：回弹，不刷新
- 若超过阈值后回拉到阈值内再松手：不刷新

### 5.5 首页文案

- 阈值前：`继续下滑刷新`
- 阈值后：`松手刷新`

## 6. 液态玻璃视觉规范（2026-05-28）

### 6.1 设计理念

- 全局采用液态玻璃（Liquid Glass / Glassmorphism）视觉语言
- 卡片、面板、顶栏等容器使用半透明毛玻璃背景，让底层渐变色透出
- 每个主题（衣/食/住/行）拥有独立强调色，渐变背景随主题切换
- 视觉层次：背景渐变 → 毛玻璃容器 → 前景内容

### 6.2 全局背景

- 页面背景为三段渐变：顶部浅色 → 中段主题色微染 → 底部中性灰
- 渐变方向统一为 `180deg`（从上到下）
- 主题强调色仅以极低透明度（6%-10%）融入渐变，不喧宾夺主

### 6.3 毛玻璃容器规格

| 属性 | 值 |
|------|------|
| 背景色 | `rgba(255, 255, 255, 0.45)` ~ `rgba(255, 255, 255, 0.65)` |
| 模糊 | `blur(20px)` ~ `blur(40px)`（小程序用 `backdrop-filter`，iOS 用 `.ultraThinMaterial`） |
| 边框 | `1px solid rgba(255, 255, 255, 0.3)` ~ `rgba(255, 255, 255, 0.5)` |
| 圆角 | 大容器 `24rpx`~`30rpx`，小元素 `999rpx`（全圆角） |
| 阴影 | `0 8px 32px rgba(0, 0, 0, 0.06)` ~ `0 12px 40px rgba(0, 0, 0, 0.10)` |

### 6.4 各组件液态玻璃规则

- **搜索框**：胶囊形毛玻璃，`rgba(255,255,255,0.5)` + `blur(24px)` + 白色半透明边框
- **「我的」图标**：圆形毛玻璃，同搜索框规格
- **推荐卡片**：大圆角毛玻璃，`rgba(255,255,255,0.55)` + `blur(30px)` + 白色半透明边框 + 柔和阴影
- **主题切换栏**：整体毛玻璃底板，选中项为更亮的毛玻璃胶囊 + 微光晕
- **详情页图集**：每张幻灯片为毛玻璃卡片
- **我的页**：profile 卡片、统计卡片、菜单卡片均为独立毛玻璃容器
- **登录页**：表单区域为毛玻璃卡片
- **跳转准备页**：面板为毛玻璃卡片

### 6.5 主题色映射

| 主题 | 强调色 | 渐变中间色 |
|------|--------|-----------|
| 衣 clothing | `#e91e8c` 粉 | `rgba(233, 30, 140, 0.08)` |
| 食 food | `#f97316` 橙 | `rgba(249, 115, 22, 0.08)` |
| 住 housing | `#14b8a6` 青 | `rgba(20, 184, 166, 0.08)` |
| 行 transport | `#3b82f6` 蓝 | `rgba(59, 130, 246, 0.08)` |

## 7. 埋点语义共识

- 事件命名按“页面_动作_结果”统一风格
- 字段命名使用 snake_case，含义跨端一致
- 至少覆盖：入口点击、主要手势、刷新触发、错误恢复

## 8. 变更流程

- 新增或修改交互：先改本文，再改分端文档，再改实现
- 分端文档不得覆盖或弱化本文的统一语义
- 若实现与文档冲突，以已评审文档为准并回修实现
