# 登录相关错误文案与 CTA（三端统一）

## 1. 使用方式

- 客户端**仅按 `code` 分支**，下列文案为**建议展示**；`message` 可作兜底，不得作为唯一判断依据。
- 展示形态：轻提示（Toast/Snackbar）、弹窗、或登录面板内联错误区；同一 `code` 在三端语义一致，仅载体适配有差异。
- 详细交互与状态机见 [frontend-login-interaction.md](./frontend-login-interaction.md)。

## 2. 文案与操作表

| `code` | 建议标题（可省略） | 建议正文 | 主按钮 / CTA | 次按钮（可选） |
|--------|-------------------|----------|--------------|----------------|
| `20006` | 登录未成功 | 验证码错误或已过期，请重新获取或重试微信授权。 | **重试**（回到对应输入/重授权） | 关闭 |
| `20005` | 暂无法登录 | 当前设备或环境受限，请稍后再试或更换网络。 | **知道了** | 联系客服（若产品有入口） |
| `10002` | 信息有误 | 请检查手机号格式或验证码是否完整。 | **修改** | — |
| `10001` | 缺少信息 | 请填写手机号或验证码后再试。 | **去填写** | — |
| `10005` | 操作过于频繁 | 请稍后再试验证码或登录。 | **稍后重试**（禁用按钮至冷却结束） | — |
| `20002` | 登录状态失效 | 正在为你刷新登录…（自动 refresh，一般不常驻展示） | —（自动） | — |
| `20003` | 请重新登录 | 登录已过期，请重新登录。 | **去登录** | 继续浏览（访客） |
| `90002` | 网络繁忙 | 服务响应超时，请检查网络后重试。 | **重试** | 关闭 |
| `90003` | 服务异常 | 暂时无法连接服务，请稍后重试。 | **重试** | 关闭 |
| `90001` | 服务异常 | 出了点问题，请稍后重试。 | **重试** | 关闭 |

## 3. 与 HTTP 状态

- 网关可能对失败返回 `401` / `429` / `502` / `504` 等，客户端仍**以 JSON `code` 为准**映射上表。
- `20001`（未带主体）多见于需 Bearer 或访客头的路由；登录面板内若误触发，正文可用：**请稍后再试或重启应用**，CTA：**重试**。

## 4. 无障碍与合规

- 错误提示避免泄露服务端细节（不展示堆栈、内部错误码字符串）。
- 手机号/验证码错误可合并使用 `20006` 与 `10002` 的友好文案，避免暗示「该手机号已注册」等敏感推断，除非产品与法务明确要求。
