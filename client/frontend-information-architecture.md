# 信息架构与核心流程

## 1. 页面地图

```text
首页 Home
  -> 导购详情 GuideDetail
      -> 跳转准备 RedirectPrepare
          -> 第三方成交平台
  -> 我的 Me
      -> 登录 Login（面板/页）
      -> 收藏 Favorites
      -> 历史 History
      -> 偏好 Preferences（未实现）
```

## 2. 主导航结构

- 主入口为 `首页`；`我的` 作为首页顶栏右侧入口
- 首页顶栏：搜索框（占位）+ 「我的」入口图标
- `首页`底部使用 4 个一级主题 Tab：`衣`、`食`、`住`、`行`（固定主题切换栏）
- 高价值转化路径保持最短：主题 Tab -> 详情 -> 去购买
- 登录采用"访客可浏览、关键动作触发登录"策略，详见 `client/frontend-login-interaction.md`

## 3. 核心任务路径

1. 用户进入首页，默认进入一个主题 Tab（可按历史偏好记忆）
2. 用户浏览卡片并理解推荐原因
3. 用户进入详情确认信息
4. 用户点击“去购买”，进入跳转准备
5. 系统返回可用 `landing_url` 并完成跳转

## 4. 三端实现一致性检查

- 是否共享同一页面结构和任务顺序
- 是否都提供 `衣/食/住/行` 四个一级 Tab，且排序一致
- 是否共享同一字段命名和错误语义
