# 品牌素材（跨 C 端）

源文件库，供 iOS / Android / 微信小程序导出平台规格（App Icon、启动图等）。**勿**在各端目录各存一份源文件。

| 文件 | 用途 |
|------|------|
| `brand/logo.jpeg` | 主 Logo（四象限 +「简」字标识） |
| `brand/少糖-方.jpg` | 方版品牌图（运营/应用商店物料） |
| `brand/少糖-圆.png` | 圆版品牌图（头像/小程序图标候选） |

接入各端前在 `client/frontend-README.md` §6 登记用途；运行时仍以文案与 `wechat-miniprogram/config/brand.ts` 等配置为主。
