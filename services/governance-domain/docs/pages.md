# governance-domain — 页面与入口

> 面向 **运营、审核、风控协同** 的后台能力。C 端导购页不在此域实现，仅说明 **需要从本域读取或写入的字段/操作**，供 BFF 与前端并行拆分。

## 1. 角色与入口

| 角色 | 典型入口 | 依赖本域能力 |
|------|----------|--------------|
| 审核员 | 审核工作台 | 待审队列、决策提交、历史记录 |
| 运营 | 内容治理台 | 可见性裁决、合作标签、风险标记 |
| 平台运营 | 运营配置中心 | 配置草稿/发布/回滚 |
| 策略/合规 | 策略管理（可与配置合并） | 策略版本、试跑结果 |

具体 URL 与前端路由由承担 BFF 职责的 **gateway** 定义；本域只保证 **API 与数据** 在 `api.md`、`data-model.md` 一致。

---

## 2. 页面清单（建议）

### 2.1 审核工作台

- **待审列表**：筛选状态、主题、渠道、优先级；支持认领/分配（若实现）。
- **审核详情**：展示内容摘要（来自 content-domain 聚合）、历史审核记录、策略命中说明、风险标记摘要。
- **提交结论**：通过/驳回/挂起；必填意见（可配置）；提交后触发工作流与事件。

### 2.2 可见性与下架

- **单内容裁决**：当前可见性、变更原因码、关联审核单、操作日志。
- **批量操作**：导入 ID 列表或筛选结果集；异步任务 + 结果通知（长耗时场景）。

### 2.3 商业合作与披露

- **主体维度的标签编辑**：选择合作类型、绑定披露模板、预览 C 端展示文案（文案模板可来自配置）。
- **模板管理**：披露模板 CRUD（权限收紧，仅平台角色）。

### 2.4 风险标记

- **打标/解标**：主体搜索、标记原因、来源、过期时间。
- **主体风险视图**：时间线，与审核、可见性联动跳转。

### 2.5 运营配置与策略

- **配置编辑**：Schema 驱动表单或 JSON 编辑器（视安全要求）；草稿 → 审批（若需要）→ 发布。
- **策略包**（若独立于通用配置）：版本列表、diff、试运行入口。

## 3. C 端与 BFF 的只读需求（非本域页面，但契约相关）

| 场景 | BFF 行为 | 本域数据来源 |
|------|----------|--------------|
| 导购卡片展示 | 组装 `guide-card` 契约字段 | `cooperation/labels`、可见性判定 |
| 内容详情页 | 过滤不可见内容或展示「不可用」 | `visibility:evaluate` 或快照 |
| 维护模式 | 全局提示条 | `ops-config` 快照 |

---

## 4. 并行开发分工建议

- **前端 / BFF**：按页面拆分子项目；与本域只通过 **已定版 api.md** 联调。
- **本域后端**：先实现 `visibility:evaluate` + `review/state` + 事件，即可解锁推荐与内容域 **最小闭环**。
- **设计**：审核台与配置台可共用设计系统；披露文案以 **模板 key** 驱动，避免硬编码在各端。
