# Web 交互实现说明

本文记录 Web 端交互实现细节，必须遵循 `../cross-platform-interaction-consensus.md`。

## 首页（Home）对齐目标

- 顶部 `衣/食/住/行`：支持点按；触控设备支持左右滑切换
- 底部导航：仅点按
- 主区：单屏单卡片
- 上滑：下一条；下滑（非第一页）：上一条；第一页下滑松手判定刷新
- click/tap 明确触发详情；pointer move 超阈值取消 click

## 登录（Login）对齐目标

- 登录入口：我的页“去登录”与受保护动作拦截统一拉起登录弹层
- 登录方式：支持 `微信登录` 与 `手机号验证码登录`
- 手机号流程：手机号输入 -> 验证码发送与倒计时 -> 验证码提交 -> 登录成功回跳
- token 过期处理：`20002` 自动 refresh 一次，`20003` 清理 token 并回到访客态
