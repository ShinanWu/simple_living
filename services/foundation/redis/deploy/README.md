# Redis 容器部署

仅管理 **Redis 容器**（`simple-living-redis`）。

QEMU 节点与三组件一键部署见 `services/foundation/deploy/`。

```bash
bash services/foundation/redis/deploy/deploy_service.sh up
bash services/foundation/redis/deploy/deploy_service.sh health
bash services/foundation/redis/deploy/deploy_service.sh down
```
